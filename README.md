# Nghịch lý Epicurus

Website tương tác nhỏ bằng HTML, CSS và JavaScript thuần để khám phá một phiên bản của nghịch lý Epicurus — câu hỏi triết học về sự tồn tại của cái ác và một vị thần toàn năng, toàn tri, toàn thiện.

## Chạy trên máy

1. Tải hoặc giải nén các tệp trong thư mục dự án.
2. Mở `index.html` bằng trình duyệt.
3. Không cần cài đặt thư viện hay chạy máy chủ.

## Đăng lên GitHub Pages

1. Tạo một repository mới trên GitHub.
2. Tải lên `index.html`, `style.css`, `app.js` và `README.md` ở thư mục gốc của repository.
3. Mở **Settings → Pages**.
4. Trong phần **Build and deployment**, chọn **Deploy from a branch**.
5. Chọn nhánh `main` và thư mục `/(root)`, sau đó nhấn **Save**.
6. Chờ GitHub Pages triển khai và mở đường dẫn được hiển thị trong phần Pages.

## Cấu trúc

- `index.html` — nội dung và khung giao diện.
- `style.css` — giao diện responsive, tông tối và điểm nhấn màu vàng.
- `app.js` — logic các câu hỏi và lựa chọn.
- `README.md` — hướng dẫn chạy và triển khai.

## Tùy chỉnh

Chỉnh sửa nội dung trong đối tượng `flow` ở `app.js` để thay đổi câu hỏi, câu trả lời hoặc nhánh hội thoại. Nút **Quay lại** luôn đưa người dùng về câu mở đầu theo yêu cầu.

## Ghi chú

Đây là một trải nghiệm triết học tương tác, không nhằm khẳng định rằng một câu trả lời duy nhất đã giải quyết toàn bộ vấn đề triết học về cái ác.
